# Daddy's Club

Маркетплейс revenue-based фінансування для onchain-протоколів на Solana.

Протокол, який уже заробляє комісії, випускає короткостроковий бонд із фіксованим
номіналом і купоном. Бонд погашається автоматично: узгоджена частка комісій
протоколу відщеплюється в момент, коли комісія виникає, і розподіляється власникам
бондів — доки не виплачено номінал плюс купон. Після цього перехоплення
припиняється саме. Бонди торгуються до погашення.

Без розмивання токена, без застави коштів користувачів і без кредитного комітету.

## Стек

Anchor 0.32.1 · Rust 1.97.1 · Agave 4.2.0 · Token-2022 з Transfer Hook ·
pnpm 9 workspaces · TypeScript 5.9 strict · Biome · Vitest · React 18 + Vite 5.

Бази даних і бекенду немає навмисно: канонічний стан живе в акаунтах Solana,
інтерфейс читає їх напряму через RPC.

## Структура

```
programs/daddys-club   ядро: випуск, ескроу, перехоплення, вторинка, transfer hook
programs/demo-issuer   референсна інтеграція: своп, що віддає частку комісії
packages/sdk           типи, деривації PDA, дзеркало арифметики
apps/web               маркетплейс, картка випуску, дашборд емітента
fixtures               спільні фікстури для арифметики Rust ↔ TypeScript
```

## Розробка

```bash
pnpm install
pnpm gate        # lint + typecheck + test
anchor build     # збірка програм
anchor test      # тести програм
```

Скопіюй `.env.example` у `.env` і заповни RPC-ендпоінт та мінт USDC для свого
кластера.
